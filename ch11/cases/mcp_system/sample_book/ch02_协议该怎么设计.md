# 第 2 章 协议该怎么设计

## 2.1 三层结构

MCP 的架构分三层：Host、Server、Transport。

### 2.1.1 Host

运行 AI 模型的主程序。它创建并管理多个 Client，决定哪些 Server 可以被调用。

### 2.1.2 Server

你真正要手搓的部分。它通过三种原语对外暴露能力。

### 2.1.3 Transport

连接 Client 和 Server 的通信通道。标准定义两种：stdio 与 Streamable HTTP。

## 2.2 三种原语

| 原语 | 控制方 | 典型用途 |
|---|---|---|
| Tools | 模型 | 函数调用 |
| Resources | 应用 | 背景数据 |
| Prompts | 用户 | 交互模板 |

## 2.3 一句话总结

协议足够简单，甚至不需要框架也能手写。
