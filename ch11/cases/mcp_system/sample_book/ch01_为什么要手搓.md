# 第 1 章 为什么要手搓

## 1.1 现成 Server 的三个假设

很多人问："GitHub 上已经有成千上万个 MCP Server，直接调用不行吗？"

这个问题暗含三个假设：你需要的工具正好有人写过、维护良好、并且恰好覆盖你的业务场景。

## 1.2 私有系统没有现成货

你所在行业的私有 API、你那套特殊的数据格式、你用了五年的内部系统——这些东西不会有现成的 MCP Server。

### 1.2.1 复用之前要先理解

手搓不是拒绝复用，而是掌握复用之前的理解。

### 1.2.2 黑盒的风险

把核心业务逻辑交给一个你完全不了解内部机制的开源项目，等于在系统里埋一颗不知道何时引爆的炸弹。

## 1.3 本文档是什么

这是一份**示例书稿**，只用来给 MCP Server 的 `count_chars`、`get_chapter_toc`、`search_book` 三个工具提供输入。

它故意很短——短到你一眼能看完，从而能手工核对工具的输出对不对。
